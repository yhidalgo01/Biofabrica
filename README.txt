DigiPROY | Prototipo de portada y cartilla de evaluación

ARCHIVOS
- index.html: pantalla principal y formulario de registro de ejemplo.
- styles.css: estilos responsivos inspirados en la imagen de referencia.
- script.js: cartillas, búsqueda, filtros, navegación y guardado demostrativo.
- assets/cabecera.png: franja superior recortada de la imagen aportada.

USO
1. Descomprima el archivo ZIP.
2. Abra index.html en Chrome, Edge o Firefox. No requiere servidor ni Internet.
3. Pulse cualquier cartilla (por ejemplo E154) para abrir el formulario.
4. Ingrese datos y pulse Guardar. El registro se almacena en localStorage del navegador, únicamente como demostración.

ALCANCE
- Portada con 12 cartillas, diseño responsive y menú inferior.
- Búsqueda por código o descripción y filtros funcionales.
- Primer formulario genérico para probar la navegación de las cartillas.
- No hay integración con API, base de datos, SAP ni autenticación.
- Los otros iconos del menú muestran un aviso de versión futura.

Para continuar el proyecto, se pueden personalizar los campos de cada cartilla y conectar servicios reales.
